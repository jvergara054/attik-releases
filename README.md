# ATTIK

Downloads for ATTIK, a floating app bar for macOS (14 or later, Apple silicon and Intel).

**[Download the latest version](https://github.com/jvergara054/attik-releases/releases/latest)**: unzip, move ATTIK.app to Applications and open it. Once installed, ATTIK updates itself.

`appcast.xml` is ATTIK's update feed.
